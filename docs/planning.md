# 企画書（たたき台）

## 1. 概要

ウェブページ上の画像の代替テキスト（alt 属性など）を、目に見える形で表示する Chrome 拡張機能。
代替テキストがない画像については、生成AIに代替テキストの案を作らせ、制作者が確認・コピーして使えるようにする。

## 2. 想定する利用者

- ウェブサイトを制作・運用する人（デザイナー、エンジニア、ライター、編集者、Web担当者）
- アクセシビリティのチェックを行う人

※ 画像が見えない・見えにくい人の閲覧支援（スクリーンリーダー向けにページの読み上げ内容を変えること）は、この拡張機能の目的に含めない。

## 3. 解決したい課題

- 代替テキストは画面に表示されないため、正しく設定されているかを確かめるには、開発者ツールでHTMLを読む必要があって手間がかかる。
- どの画像の意味がスクリーンリーダーの利用者などに伝わっていないのかを見分けにくい。
- 代替テキストを書くこと自体に慣れておらず、何を書けばよいかわからない人が多い。

## 4. 提供する価値

- ワンクリックで、ページ内のすべての画像の代替テキストの状態がわかる。
- 問題のある画像がひと目でわかる。
- 代替テキストの案をAIに出してもらい、書くための出発点にできる。

## 5. 設計思想

- 画面に出す警告や情報は最低限にした、ミニマムな拡張機能にする。
- 利用者にアクセシビリティの知識（WAI-ARIA やアクセシブルな名前の決まり方など）があることは期待しない。
- 代替テキストはアクセシブルな名前の計算ルールに従って求めるが、その仕組みを画面上で説明することはしない。
  （例：`aria-label` が優先されて、alt 属性を変えても表示が変わらないことがある。この点の説明は、別途ドキュメントなどで後から対応を考える）

## 6. 機能

### フェーズ1：代替テキストの表示（最初の公開版）

| 機能 | 内容 |
|---|---|
| 表示の切り替え | ポップアップで、今開いているタブの表示をオン・オフする |
| 代替テキストの表示（標準） | 画像を消し、その場所に代替テキストを表示する |
| 代替テキストの表示（画像も表示） | ポップアップで切り替えると、画像を表示したまま、画像の近くに代替テキストを表示する |
| 代替テキストがない画像の表示 | 代替テキストがない場合は「スクリーンリーダーユーザーなどには意味が伝わらない画像がここにあります」と表示する |

対象は `<img>` 要素と、`role="img"` が指定された要素。詳しくは `docs/spec.md` を参照。

### フェーズ2：AIによる代替テキストの提案

| 機能 | 内容 |
|---|---|
| 提案の作成 | 利用者が画像を選んでボタンを押したときだけ、画像をAIに送って代替テキストの案を作る |
| 結果の表示 | 「AIによる提案」とわかる形で表示し、ワンクリックでコピーできるようにする |
| APIキーの設定 | 利用者が自分のAPIキーを設定画面（options）で入力する |

### 対象外（今回はやらないこと）

- ページのHTMLを書き換えて、代替テキストを恒久的に保存すること
- スクリーンリーダー向けに、ページの読み上げ内容を変えること（表示中は拡張機能が入れたテキストも読まれるが、それを目的とはしない）
- ページ内の全画像をまとめて自動でAIに送ること

## 7. 方針

### permissions

- フェーズ1は `activeTab` と `scripting` だけで実現する（常にすべてのサイトで動かすことはしない）。
- フェーズ2では、AIサービスへの通信のために `optional_host_permissions` を使い、AI機能を使う時だけ利用者に許可を求める。

### プライバシー

- 画像は、利用者が明示的に操作した時だけ外部（AIサービス）に送る。
- APIキーは `chrome.storage.local` に保存し、ほかの端末と同期しない。
- 開発者のサーバーは使わない（利用者のブラウザからAIサービスへ直接送る）。
- ウェブストアへの公開時に、プライバシーポリシーを用意し、データ利用の申告をする。

### セキュリティ（Manifest V3）

- 外部から取得したコードは実行しない。
- AIからの返答は `textContent` で表示し、HTMLとしてページに挿入しない。

### アクセシビリティ

- 拡張機能の画面（ポップアップ・設定画面・ページ上のラベル）は、キーボードだけで操作できるようにする。
- スクリーンリーダーで読み上げられるように、適切な要素とラベルを使う。
- 十分なコントラストを確保し、色だけで情報を伝えない。
